# Rule Sources Registry

Last audit: 2026-08-20

## Maintenance Policy

- No guessing.
- Track upstream by file-level commit SHA and downloaded file SHA256.
- A date in a generated file header is not sufficient evidence of freshness.
- Any upstream change requires review before production use.
- Changes are tested in `shadowrocketzh` before production sync.
- Evidence insufficient = no change.

The `Count` field below is parsed from the downloaded file after comments and blank lines are removed. The value after `/` is the file header `TOTAL` when present. For providers with an `_Domain.list` companion, the header total describes the combined generated provider: for example, Tencent is 25 main-file rules plus 2,498 domain-set entries = 2,523. This is an intentional split, not a file corruption finding.
